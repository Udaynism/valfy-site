Valfy Kebijakan Privasi

Kebijakan Privasi

Berlaku sejak 3 November 2026

Kebijakan ini menjelaskan data apa yang dipakai aplikasi Valfy dan ke mana data itu disimpan. Singkatnya: semua catatan keuanganmu tetap di HP-mu dan di Google Drive milikmu sendiri. Pengembang Valfy tidak menerima, melihat, atau menjual datamu.

Data yang kamu catat

Transaksi, akun, anggaran, tujuan, utang-piutang, kategori, dan pengaturan yang kamu isi disimpan di database di dalam HP-mu. Valfy tidak punya server, tidak memakai iklan, dan tidak memakai layanan analitik atau pelacak. Data ini tidak dikirim ke pengembang atau pihak lain.

Akun Google dan cadangan di Google Drive

Menghubungkan akun Google bersifat pilihan dan hanya dipakai untuk cadangan. Jika kamu menghubungkannya:

  • Valfy membaca alamat email akun Google-mu untuk menampilkan akun mana yang terhubung.
  • Valfy meminta izin drive.appdata, yang hanya memberi akses ke folder khusus aplikasi di Google Drive milikmu. Valfy tidak bisa melihat, membaca, atau mengubah file lain di Drive-mu.
  • File cadangan berisi data yang kamu catat di Valfy. File ini disimpan langsung dari HP-mu ke Google Drive-mu, tanpa melewati server lain.

Pemakaian informasi yang diterima dari Google API mengikuti Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas (Limited Use).

Izin lain di HP

  • Kamera dan galeri: hanya saat kamu melampirkan foto struk. Foto disimpan di HP-mu.
  • Sidik jari atau pengenal wajah: untuk membuka kunci aplikasi. Data biometrik diproses oleh sistem HP dan tidak pernah diterima Valfy.
  • Notifikasi: untuk pengingat yang dijadwalkan di HP-mu sendiri.

File yang kamu bagikan

Saat kamu membuat cadangan ke file atau ekspor CSV, file dibuat di HP-mu dan dibagikan ke aplikasi yang kamu pilih. Setelah itu file berada di bawah kendalimu.

Menghapus data

  • Data di HP terhapus jika kamu menghapus aplikasi atau menghapus data aplikasi di pengaturan HP.
  • Untuk memutus akses Google, pilih Putuskan akun Google di layar Cadangan dan pemulihan Valfy, atau buka myaccount.google.com/connections.
  • Untuk menghapus file cadangan di Google Drive, buka Google Drive di web, pilih Setelan → Kelola aplikasi, lalu pada Valfy pilih Opsi → Hapus data aplikasi tersembunyi.

Anak-anak

Valfy tidak ditujukan untuk anak di bawah 13 tahun.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dimuat di halaman ini dengan tanggal berlaku yang baru.
